## Getting started

Clone this collection:

```bash
git clone https://github.com/AnasBouzanbil/JS_TS_Projects.git
cd JS_TS_Projects
```

Choose a project from the table above. Each folder is a separate project; there is no shared root-level install or start command. Check the selected project's README and `package.json` for its dependencies and available scripts.

For the WebRTC client, see its [README](./WebRtc/client/README.md).
